# Heart Disease Prediction Using Machine Learning

## Project Overview

This project focuses on predicting the possibility of heart disease using Machine Learning algorithms and patient health information.

Developed using Python in Google Colab, the project covers data preprocessing, exploratory data analysis, model training, model evaluation, and an interactive prediction interface.

## Objectives

- Perform data cleaning and preprocessing.
- Explore important features and relationships.
- Visualize patterns through data analysis.
- Train and compare multiple Machine Learning models.
- Evaluate model performance using different evaluation metrics.
- Develop an interactive heart disease prediction system.

## Technologies and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Google Colab
- IPyWidgets

## Machine Learning Algorithms

The following classification algorithms were implemented:

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)

## Project Workflow

1. Data loading and exploration.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis (EDA).
4. Data visualization.
5. Feature and target separation.
6. Machine Learning model training.
7. Model evaluation and comparison.
8. Interactive prediction interface development.

## Model Evaluation

The models were evaluated using the following performance metrics:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC Score
- 5-Fold Cross-Validation
  

## Interactive Prediction System

An interactive prediction form was developed using IPyWidgets in Google Colab.

Users can enter patient health information and receive a model-generated prediction with class probabilities.

## How to Run the Project

1. Clone or download this repository.
2. Open the notebook in Google Colab.
3. Upload the required input file when prompted.
4. Run the notebook cells in sequential order.
5. Complete the interactive form to generate predictions.
